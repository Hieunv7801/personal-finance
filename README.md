# Money Flow\n\nNext.js 16 + Supabase app cho quản lý dòng tiền theo kỳ lương **15 → 14**.\n\n## Logic\n- Transactions là source of truth.\n- Không có fallback lương kế hoạch vào Actual. Muốn kỳ có thu nhập, phải nhập `Lương | Thu`.\n- Dashboard tự dùng ngày thật để xác định kỳ.\n- Trả nợ không tính vào budget sinh hoạt nhưng tính vào tổng tiền ra.\n- Kỳ lương tự gom 15/tháng này → 14/tháng sau.\n\n## Setup Supabase\n1. Tạo Supabase project.\n2. SQL Editor → chạy `supabase/schema.sql`.\n3. Authentication → Email provider bật sẵn mặc định.\n4. Copy Project URL + Publishable key.\n\n## Env\n```bash\ncp .env.example .env.local\n```\nĐiền:\n```env\nNEXT_PUBLIC_SUPABASE_URL=...\nNEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=...\n```\n\n## Local\n```bash\nnpm install\nnpm run dev\n```\n\n## Deploy Vercel\nPush GitHub → Import vào Vercel → thêm 2 env vars ở trên → Deploy.\n\nKhi dùng thật từ 15/09/2026, mỗi kỳ nhận lương phải thêm transaction thực tế, ví dụ:\n`15/10/2026 | Nhận lương | Lương | Thu | 21.600.000`\nSau đó chỉ thao tác ở Transactions; Dashboard và Các kỳ lương tự chạy.\n
